# FinControl

Plataforma de controle financeiro pessoal que ajuda o usuário a acompanhar receitas e despesas, e gera relatórios automáticos com insights sobre economia.

## 🚧 Status do projeto
Em desenvolvimento — construído como projeto de estudo, documentando o processo do zero ao deploy.

## 🛠️ Tecnologias
- **Backend:** Python, Django, Django REST Framework
- **Banco de dados:** PostgreSQL (hospedado no Supabase)
- **Autenticação:** JWT (djangorestframework-simplejwt)
- **Frontend:** React
- **Outros:** python-decouple (variáveis de ambiente), django-cors-headers
